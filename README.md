## Questão 01:
#### Usar getters e setters no lugar de deixar os atributos públicos é uma forma mais segura e organizada de lidar com os dados de uma classe. Isso porque eles ajudam a controlar o que pode ou não ser feito com os valores, evitando que algo errado seja colocado ali por engano. Por exemplo, se a gente tiver uma classe "Pessoa" com um setter para a idade, dá pra impedir que alguém coloque uma idade negativa, o que faria sentido. Além disso, se um dia for preciso mudar a forma como os dados são tratados, isso pode ser feito sem quebrar o resto do código.
